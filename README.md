# tukuk-nasa

Tukuk-OS NASA — NASA APOD, asteroids, and EPIC data.

## Folder Structure

```
tukuk-nasa/
├── .github/workflows/ci.yml   # GitHub Actions CI
├── .gitignore                 # Git ignore rules
├── package.json               # Node.js manifest
├── README.md                  # This file
├── data/apod.json             # NASA APOD data
├── data/asteroids.json        # NASA asteroids data
└── data/epic.json             # NASA EPIC data
```

## CI/CD

Push atau pull request akan menjalankan workflow CI di GitHub Actions.
